📊 Instagram Engagement and Lifestyle Dashboard
📌 Overview
This repository contains an interactive Power BI dashboard that analyzes Instagram usage patterns, user engagement, and lifestyle-related factors. The dashboard transforms raw data into meaningful insights using KPIs, charts, and interactive visualizations.
The project demonstrates how social media behavior can be analyzed alongside factors such as sleep, stress, exercise, engagement, privacy settings, and content preferences.
🎯 Objective
Analyze Instagram user engagement and activity
Identify relationships between lifestyle habits and social media usage
Visualize trends through interactive dashboards
Practice real-world data analysis using Power BI
